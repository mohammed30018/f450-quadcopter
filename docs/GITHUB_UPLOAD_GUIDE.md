# GitHub Upload – Schritt für Schritt

1. ZIP-Datei entpacken.
2. Auf GitHub ein neues Repository erstellen, z. B. `f450-quadcopter`.
3. Im Repository `Add file` → `Upload files` wählen.
4. Die Datei `README.md` und den Ordner `docs` aus diesem Paket hochladen.
5. Prüfen, dass die Ordnerstruktur so erscheint:
   - `README.md`
   - `docs/photos/`
   - `docs/diagrams/`
   - `docs/references/`
6. Commit message: `Add F450 quadcopter project documentation`
7. `Commit directly to the main branch` auswählen und `Commit changes` drücken.

Nicht hochladen:
- vollständige Herstellerhandbücher aus dem privaten ZIP, sofern keine Freigabe zur öffentlichen Weitergabe vorliegt;
- fremde Referenzfotos ohne passende Nutzungsrechte;
- Konfigurations-Backups mit persönlichen Daten, Seriennummern oder Zugangsdaten.
